## Reproduction and mastering

After preparing the documented PCM narration and CC0 footstep derivatives, run `node episodes/006-gema-di-underpass/build-assembly.cjs`, `npm run check`, and `npx remotion render src/index.ts Arc01Episode06 <new-premaster.mp4> --codec h264 --concurrency 4`. Choose a new output name to preserve existing artifacts. Narration PCM was created with `asetpts=N/SR/TB`; footsteps use 130 Hz high-pass, 4500 Hz low-pass and `aecho=0.8:0.65:95:0.35`.
