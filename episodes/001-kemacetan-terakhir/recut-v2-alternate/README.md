# Alternate Episode 001 assembly

Composition `KemacetanTerakhirMotionComicAlternate` is a second, JSON-driven **preview** using the same authorized narration and existing artwork as the [main recut](../recut-v2/brief.md). It changes the early driver and crowd views, moves several shot boundaries, and uses the blueprint version of the blocked-road graphic. It is not a separate story or an independent production-throughput test.

The [manifest](manifest.json) and [captions](captions.json) use the same shared engine and are validated by `npm run check`. They can be regenerated in a fresh directory with `node scripts/create-alternate-demo.mjs`; the script refuses to overwrite an existing alternate. Studio loaded the composition without console errors and five stills rendered. No full playback, independent viewer evaluation, audio review or MP4 export has been performed for this alternate.

The alternate assembly and initial checks took approximately 65 seconds of wall-clock time, from 13:57:15 to 13:58:20 Jakarta time on 19 November 2026, after the engine, narration and artwork already existed. This measures neither a new episode from scratch nor a sustainable 2–3 videos/day workflow. Exact total time for the first cut was not recorded. All caption, voice and publication limitations from the [main review](../recut-v2/review.md) also apply here.
