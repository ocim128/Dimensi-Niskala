# Survival Fantasy Content

This is the working playbook for an AI agent making original survival-fantasy videos in the parent Remotion project for TikTok and YouTube. It is a starting thesis, not a fixed brand bible. No account or channel name or series canon has been confirmed yet.

## Start here

For the next production of *Kemacetan Terakhir*, open the [attempt 4 remake task](episodes/001-kemacetan-terakhir/attempt-04/remake-task.md) from the parent Remotion workspace. It builds on the [attempt 3 reference comparison](episodes/001-kemacetan-terakhir/attempt-03/reference-audit.md).

1. Read [the creative thesis](creative-thesis.md), [visual direction](visual.md), [language and audio](language.md), and [narration voice profile](voice-profile.md).
2. Follow [the production workflow](workflow.md) and use the [episode brief](templates/episode-brief.md).
3. Build the video with the existing Remotion project using [the technical guide](remotion-production.md).
4. Use the [review checklist](templates/review.md), then record feedback using [the learning loop](feedback-loop.md) and [experiment log](experiments.md).
5. Use [publishing guidance](publishing.md) when the owner is ready to post.

The agent prepares and reviews content; the owner decides whether to publish. Producing a video or publishing it requires an actual request or other clear authorization. This playbook itself does not authorize a video, an upload, or account changes.

## Current starting assumptions

| Decision | Working default | Status |
| --- | --- | --- |
| Audience | People who enjoy imagined survival dilemmas, mystery, and fantasy worlds | Hypothesis |
| Format | Vertical, standalone short-form episodes with optional recurring continuity | Hypothesis |
| Story | Create an unbelievable experience through a survival situation in a fantasy world; explore the format | Owner's goal; format open |
| Language | Indonesian narration and matching captions | Owner's choice |
| Narrator | Masculine Indonesian male voice around 40, firm, confident and expressive | v4 selected for now; accent improvement uncertain and pacing may be faster |
| Tone and look | Tense, curious, readable; stylized, diagram-friendly visuals | Hypothesis |
| Production destination | A new episode subfolder under `episodes/` | Current workflow |

Reference media is kept outside this content folder for reviewer analysis. For blind production tests, the production agent receives only a written brief and permitted assets; do not search for or inspect reference media or repository history. This is a workflow separation, not an access-control guarantee.
